# Fast Windows
A Quick Python Application to De-Slop-pify Windows.

Step 0 : Clam Down, let Windows Updates happen.

Step 1 : Install Python

``` shell
winget install python3 -s winget
```

Step 2 : Add it to PATH 

> Remove `%USERPROFILE%\AppData\Local\Microsoft\WindowsApps` for User's PATH.
>
> Need to Re-Test, But rest of the things will work.
